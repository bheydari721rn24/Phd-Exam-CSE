# Rebuild the active linear-transformation chapter

Run from the study-planner repository using Python with SymPy, markdown-it-py, requests and websocket-client. The independent PDF acquisition/rendering helper additionally needs PyMuPDF. The runtime used for this delivery was C:/Users/bheydari/miniconda3/python.exe. Node runs the actual browser calculator oracle.

1. Run research/write_l_linear_bank.py to reset the authored bank and its exact computed certificates.
2. Run research/prepare_l_linear.py to build all model instances, match calculation-question visuals, and verify native examination hashes.
3. Run research/prepare_l_linear_js.py to build the exact rational coordinate laboratory.
4. Run research/render_l_linear.py to render only this chapter, its audits and its one library entry. Prior chapter pages are never rebuilt.
5. Run research/prepare_l_linear_qa.py to prepare the actual Edge harness.
6. Run research/verify_l_linear.py and research/qa_l_linear_browser.py. Each writes its own evidence report. Inspect representative captures before accepting the result.

Source acquisition is independently repeatable with research/prepare_l_linear_sources.py; a successful download does not establish that its contents were read. Actual human-readable review records and native page ranges are in reading.json and the source audit.

research/finalize_l_linear.py is a **one-time gate handoff**, already performed. Do not rerun it while a different chapter is current. It records the audited draft, preserves studentApproved:false, establishes the next chapter's prior-library baseline, and appends the delivery log. Publication metadata is written only after deployment confirmation.
