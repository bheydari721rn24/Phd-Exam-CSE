It can compare those bounded arrays and return based on the first mismatch or equality over all three. `strcmp` requires complete terminated strings and, if no earlier mismatch establishes a result in a particular implementation, cannot be justified by these unterminated objects; the string precondition is absent. A valid bounded prefix interface and a valid whole-string interface carry different contracts. Both still require valid pointer values and appropriate readable bytes.
---RULE---
Bounded comparison can operate on a sufficiently readable nonterminated prefix; whole-string comparison requires string objects.

@@ 76|An overlap check itself needs a domain|Original advanced pointer-contract problem
A programmer attempts to detect arbitrary pointer-range overlap with `if(dst<src+count && src<dst+count)`. Why is this not a universally portable check for unrelated C objects? How can an interface avoid the problem?
---SOLUTION---
Relational pointer comparisons and pointer arithmetic have object-domain restrictions. Forming `src+count` requires that the offset stay within its array or one-past, and relational ordering between unrelated objects is not a general portable total-address comparison. A formula valid for integer intervals in a flat model does not automatically become valid C pointer code. One design accepts a single array base, its capacity, and validated integer offsets; then both ranges are described within one object. Another states nonoverlap as a caller precondition or simply uses `memmove` for a valid requested move.
---RULE---
Prove the domain of an overlap test itself; flat numerical address reasoning does not authorize arbitrary C pointer ordering.

@@ 77|Storage states conditioned on length|Original combinatorial ratio
A capacity-$C$ array uses zero plus $q\ge1$ nonzero byte values. For a fixed length $j<C$, determine the number of complete states and the number of states per abstract value. Specialize to $C=6,q=3,j=2$.
---SOLUTION---
The first $j$ bytes are nonzero, giving $q^j$ choices; the next byte is fixed zero; the final $C-j-1$ bytes have $(q+1)^{C-j-1}$ choices. Total states are $q^j(q+1)^{C-j-1}$, and each of the $q^j$ abstract values has $(q+1)^{C-j-1}$ representations. For the specialization, there are $3^2\cdot4^3=576$ states and 64 states per value. The multiplication counts independent storage positions. It does not treat padding variants as different visible strings.
---RULE---
Conditioning on first-zero position fixes termination but leaves the suffix unrestricted; factor visible value choices from hidden storage choices.

@@ 78|Concatenation versus raw copying|Original embedded-zero synthesis
Let `char s[]="ab\0cd";` and let a large zero-initialized destination begin with `"X"`. Compare appending with `strcat(d,s)` and copying all six source bytes to `d+1` with `memcpy`. What does the destination print as a string in each case?
---SOLUTION---
`strcat` sees source length 2 and appends `a b 0`, so the destination's visible value is `Xab`. Copying all six source bytes stores `a b 0 c d 0` after `X`, preserving the source's hidden suffix too. The destination still prints as `Xab` because its first zero is at index 3. Equal printed values do not imply equal copied byte regions. The raw copy's count comes from the source array extent, while the append count comes from its string view. Both operations require sufficient disjoint valid storage.
---RULE---
Embedded zeros separate byte-region copying from string concatenation even when the visible output happens to agree.

@@ 79|A proof of bounded matching safety|Original invariant synthesis
For the displayed naive matcher with $0<m\le n$, prove every read `t[i+j]` stays inside the text content and every candidate start is considered at most once. What changes for finding all overlapping matches?
---SOLUTION---
The outer loop establishes $0\le i\le n-m$; the inner loop establishes $0\le j<m$. Hence $i+j\le n-m+m-1=n-1$, so each text content read is in range; pattern indices are likewise below $m$. Increasing `i` by one visits each feasible start in increasing order exactly once. For first-match search, the outer invariant excludes all smaller positions before a return. To find all overlapping matches, record success and continue with `i+1` instead of returning. Skipping ahead by $m$ would adopt a different nonoverlap policy and miss valid starts.
---RULE---
Combine outer and inner index bounds to prove memory safety, then state the post-match advance policy independently.

@@ 80|Combined capacity, mutation, and cost audit|Original final synthesis|append-fit
A capacity-10 array begins with `"orbit"`. Append `"XY"`, delete content indices 1 and 2, then reverse the remaining content. Derive every intermediate length and value, each direct move/write count, and the final terminator index.
---SOLUTION---
Initial length is 5. Appending two bytes requires eight storage bytes and fits capacity 10; it writes `X`, `Y`, zero, giving `orbitXY` of length 7. Deleting positions 1 and 2 removes `r` and `b`; the suffix beginning at old index 3 contains `i t X Y 0`, five moved bytes, yielding `oitXY` of length 5. ---RULE---
