# Source and boundary audit — a_model

Date: 2026-09-30. Chapter: **Computation model and input size**, the first chapter of Data Structures and Algorithms. This audit covers the precise problem/algorithm distinction; encoding and size parameters; word-RAM and bit-cost models; memory and output costs; comparison-model restrictions; worst-case and instance-dependent resource functions; and model-dependent lower bounds. Formal asymptotic notation, nested-loop counting, sorting algorithms, hashing, and recurrence solving belong to later chapters. Archived Iranian entrance-exam booklets were intentionally not consulted, as directed by the student.

## Synthesis and checks

1. MIT and Princeton agree on unit-cost word operations and explicit RAM memory cells. CMU sharpens the requirement that operands must fit in a bounded number of words; Stanford motivates the bit-length view with digit multiplication; Berkeley demonstrates its consequence for numeric dynamic programming.
2. The word-width condition is stated precisely: indexing n word-addressable locations numbered 0 through n−1 requires **w ≥ ⌈log₂ n⌉** bits when n≥2; storing the integer n itself requires **⌈log₂(n+1)⌉** bits. These are different claims. A word-RAM may instead assume w is large enough for all addresses used by the algorithm. The simplified w=Θ(log n) convention requires an address-space and key-size bound.
3. A lower bound from reading all input words is conditional: it applies if a required output can change when **any** unread word changes and the input is not already summarized. Random access permits sublinear queries when that condition fails.
4. An n×n matrix has n² scalar entries; a graph adjacency list requires Θ(V+E) *words* under word-size vertex identifiers, while a dense adjacency matrix uses Θ(V²) bits or Θ(V²) word cells depending on layout. Distinguish representational space from the graph's abstract counts.
5. If a positive integer U is binary-encoded, its length is ⌊log₂ U⌋+1, not U. An nU-state algorithm is not polynomial in a bit-length input bound merely because it is polynomial in U. The full encoding must include all n values and their bit lengths.
6. All worked exercises in the chapter are newly worded. University examples inform the reasoning types; no copyrighted problem set is copied. Source links appear again at the chapter end.

## Remaining limits

The precise instruction set varies across word-RAM conventions, and practical runtimes vary with compiler, caches, allocation, and input distribution. The chapter fixes its own convention before using a cost claim. It does not assert that five courses are globally best or guarantee every unseen exam question; it aims to eliminate identified errors within its stated boundary.
